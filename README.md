Compare POM (Page Object Model) and Procedural Design Pattern Automation Script

## How to run

1. [Install python](https://www.python.org/downloads/)
2. [Install uv](https://docs.astral.sh/uv/getting-started/installation/)
3. Run command `uv run python3 -m pytest -vv --browser chromium --slowmo 1000`

## Dependency

- [Playwright Python](https://playwright.dev/python/): Automation tools by Microsoft
